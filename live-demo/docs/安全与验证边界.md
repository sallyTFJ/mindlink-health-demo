# 心脑灵犀：安全与验证边界

## 产品可以说什么

- 实时采集并显示 ThinkGear Fp1 单通道 EEG。
- 读取标准 BLE 心率与血压测量，或接收厂商健康平台/手机伴侣转发的数据。
- 在信号连续、接触质量合格时生成 attention 与 valence 研究代理分数。
- 依据个人短期基线和主动反馈提供低风险暂停、呼吸、活动、联系真人等建议。
- 在用户完成困难任务后给予语音肯定。

## 产品不能说什么

- 不能声称从单通道 EEG 确诊或准确识别焦虑、抑郁、躁狂、癫痫、暴力倾向或自伤风险。
- 不能把模型 `valid=true` 描述成心理判断可信；它只代表输入协议、连续性和质量检查通过。
- 不能把心率升高直接解释成情绪问题。
- 不能承诺华为、苹果或任意品牌手表都能直接被 Windows 蓝牙读取。
- 不能自动启动电刺激、给出刺激参数或代替专业评估。

## 闭环分级

|级别|触发|允许的产品行为|
|---|---|---|
|安静监测|数据稳定或不足|显示来源、质量和有效性，不主动打扰|
|温柔提醒|多次相对基线组合波动，或用户反馈紧绷|低负担语音、呼吸/补水/离屏建议；明确“不是诊断”|
|真人支持|仅用户主动选择“我现在不安全”|建议不要独处、联系可信任的人、远离危险环境；危险正在发生时联系当地紧急援助|
|专业设备辅助|用户主动查看|只显示专业指导与合规使用边界；不自动连接、控制或推荐参数|

## 现场验收

1. 合成演示必须始终显示“合成演示”，不得混作真人数据。
2. 真实 EEG 断流 1.5 秒后应失效；心率 15 秒无新事件后应失效。
3. 接触质量不为 0 时不得产生新的有效模型输出。
4. 被动信号无论怎样波动，都不得进入 `urgent`；只有 `unsafe` 主动反馈可以进入。
5. 语音首次使用必须由用户点击开启，自动语音有冷却时间。
6. 现场开始前做 5–10 分钟静坐基线、断开恢复与串口独占测试。
