LIVE CONNECTION

现场连接顺序

  1. 先启动实时服务：双击 START_MINDLINK_LIVE.cmd。
  2. 连接 EEG：在 config.json 设置 eeg_mode 为 serial，并填写 ThinkGear 的 COM 端口；重启服务。
  3. 连接手表：Apple Watch 打开 HeartCast，或让兼容设备广播标准 BLE 心率服务，再双击 START_WEARABLE_BRIDGE.cmd。
  4. 华为/其他平台：通过官方健康平台或手机伴侣，将数据 POST 到本机 /api/v1/wearable。

一个 COM 端口只能被一个程序占用。现场先完成 5–10 分钟静坐基线和断流测试。

SAFETY BOUNDARY

关于局部电刺激

MindLink 当前只提供“可考虑咨询专业人员”的文字提示，不控制刺激硬件，也不推荐任何刺激参数。

  • 仅使用合法合规且适用于本人的设备。
  • 由医生或合格专业人员确认适用性与禁忌。
  • 不要在驾驶、洗浴、睡眠或无法及时停止时使用。
  • 出现疼痛、头晕、皮肤异常或其他不适时立即停止并寻求专业帮助。
